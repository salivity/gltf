How Museums Digitize Artifacts into 3D glTF Files

Museums digitize historical artifacts into archival glTF formats through a structured pipeline that combines high-precision optical capture, detailed mesh optimization, and standardized web-ready conversion. By utilizing techniques such as photogrammetry and structured light scanning, conservators create high-resolution digital twins that capture micro-textures and precise geometry. These master models are then optimized using retopology and Physically Based Rendering (PBR) texture baking before being exported to the open-standard glTF (Graphics Library Transmission Format) specification, enabling interactive, cross-platform 3D viewing on modern web browsers without specialized plugins.

1. High-Resolution Data Capture

The digitization process begins with non-invasive surface capture using two primary methods:

  • Photogrammetry: Technicians capture hundreds to thousands of overlapping high-resolution photographs of an artifact from every angle under diffuse, cross-polarized lighting to eliminate harsh reflections.
  • Structured Light or Laser Scanning: Optical 3D scanners project precise light patterns or lasers onto the object to capture sub-millimeter geometric data, particularly useful for objects with complex geometry or monochromatic surfaces.

2. Mesh Reconstruction and Alignment

The raw capture data is processed in specialized software (such as Agisoft Metashape or RealityCapture). The software identifies overlapping anchor points across the dataset to generate a dense point cloud, which is then calculated into a high-polygon triangular surface mesh. This master archival mesh often contains tens of millions of polygons, representing the artifact in its rawest, most detailed digital state.

3. Mesh Optimization and Retopology

Raw master meshes are far too large for smooth delivery over the internet. 3D specialists perform decimation and retopology to create a lightweight, optimized version of the 3D model:

  • Decimation: The polygon count is reduced from millions of triangles to an efficient budget (typically 50,000 to 200,000 polygons) suitable for real-time mobile and desktop rendering.
  • UV Unwrapping: The optimized 3D model is mathematically flattened into a 2D coordinate system (UV map) to prepare it for surface texturing.

4. Physically Based Rendering (PBR) Texture Baking

To retain the rich visual appearance of the high-polygon master scan on the lightweight model, technicians "bake" surface details into specialized PBR texture maps:

  • Normal Maps: Simulate fine surface cracks, carvings, and micro-details by altering how light interacts with the low-poly surface.
  • Base Color (Albedo): Captures true surface color without shadows or specular highlights.
  • Roughness and Metallic Maps: Accurately define how matte, glossy, or metallic various sections of the artifact are (e.g., distinguishing rusted iron from polished gold).

5. Archival glTF / GLB Conversion

Once the mesh is optimized and textured, it is exported into the glTF standard—maintained by the Khronos Group—often as a self-contained binary file (.glb). Museums prioritize glTF because it natively supports PBR workflows, packs texture maps efficiently, and provides rapid loading times via WebGL and WebGPU. Crucially, the glTF specification allows institutions to embed archival metadata (such as acquisition numbers, historical context, and licensing) directly within the file hierarchy.

6. Web Deployment and Public Access

The final .glb or .gltf asset is integrated into digital repository management systems and embedded into museum web pages using standard Web-based 3D viewers, such as Google's <model-viewer> web component, Three.js, or Babylon.js. These viewers allow researchers and the general public to rotate, zoom, inspect lighting, and even place the artifact into real-world spaces using smartphone-based augmented reality (AR).
