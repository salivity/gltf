glTF Default Fallback Material Visual Attributes

When a 3D model primitive in a glTF 2.0 file lacks an explicitly assigned material, runtimes must render it using a standardized fallback material based on the Physically Based Rendering (PBR) metallic-roughness workflow. This article breaks down the visual attributes and parameter values defined by the official glTF specification that dictate the baseline appearance, surface properties, and visibility of untextured geometry.

Base Color

The fallback material sets the baseColorFactor to [1.0, 1.0, 1.0, 1.0], representing pure, fully opaque white with no texture applied. Because the color components are at their maximum values, the material acts as a neutral canvas that does not tint incoming light, reflecting 100% of the diffuse light spectrum allowed by the surrounding lighting environment.

Metallic and Roughness Properties

Surface reflectance and microfacet dispersion are governed by two core PBR factors:

  • Metallic Factor (metallicFactor): Set to 1.0. A value of 1.0 defines the surface as a pure metal (conductor). In a standard PBR model, this means the base color is treated entirely as the specular reflectance color rather than a diffuse albedo.
  • Roughness Factor (roughnessFactor): Set to 1.0. A value of 1.0 defines a maximally rough microfacet surface.

Combined, a metallic factor of 1.0 and a roughness factor of 1.0 produce a completely matte surface where specular highlights are spread so broadly across the geometry that the material appears chalky and non-glossy, devoid of sharp reflections.

Surface Emission and Occlusion

  • Emissive Factor (emissiveFactor): Set to [0.0, 0.0, 0.0]. The fallback material emits no self-illumination and relies entirely on external environmental light or point light sources.
  • Ambient Occlusion: By default, no occlusion texture is present, implying an occlusion strength of 1.0. Crevices and recessed geometry receive full indirect ambient light without synthetic micro-shadowing.
  • Normal Mapping: No tangent-space normal texture is supplied; surface orientation relies strictly on the primitive's vertex normals or flat-interpolated face normals.

Alpha and Face Culling Settings

  • Alpha Mode (alphaMode): Set to "OPAQUE". The geometry ignores any transparency calculations, forcing all fragments to write directly to the depth buffer at 100% opacity. The alphaCutoff defaults to 0.5, though it remains inactive under the opaque mode.
  • Double Sided (doubleSided): Set to false. Back-face culling is enabled by default, meaning any surface polygons facing away from the camera are not rendered unless explicitly reversed or configured by the application.
